# App 审核说明

Lemon 是使用系统 WKWebView/WebKit 的通用 macOS 浏览器，不包含其他浏览器引擎，不下载或执行用于改变 App 功能的代码。

App 无需账号即可使用。启动后可直接在地址栏输入任意公开网址。建议审核以下功能：

1. 新建、切换和关闭标签页。
2. 点击地址栏右侧星标保存书签，并在设置中打开书签管理器。
3. 从“窗口 → 下载管理器”查看下载状态。
4. 点击地址栏左侧网站信息图标查看权限和网站数据。
5. 从“显示 → 网页检查器”检查当前标签页。

摄像头和麦克风权限仅在用户访问需要相应能力的网站并作出选择后申请。密码保存在 macOS 钥匙串；书签、历史、下载记录和加密会话均仅保存在本机。App 不包含广告、分析 SDK或开发者遥测，不向开发者收集用户数据。

商店构建会排除仅供旧版本迁移使用的 360 浏览器本机接收服务，以及针对特定第三方影视站的兼容脚本。

如审核需要测试网站登录功能，可使用审核人员自有的任意公开网站账号；Lemon 本身不提供或要求服务器账号。
