# Lemon App Store 中文资料

## 名称

Lemon

## 副标题

轻量、原生的 macOS 浏览器

## 关键词

浏览器,网页,WebKit,书签,标签页,下载,隐私,密码,macOS

## 推广文本

使用系统 WebKit 的原生 macOS 浏览器，提供标签页、书签、下载、网站权限、密码保存与隐私浏览等日常能力。

## 描述

Lemon 是一款专为 macOS 构建的轻量浏览器，使用系统 WebKit，在保持原生体验的同时提供完整的日常浏览功能。

主要功能：

• 标签页、固定标签页与会话恢复
• 书签栏、书签文件夹和书签管理器
• 下载管理、暂停、续传和完成提醒
• 地址栏搜索、浏览历史与页面内查找
• 网站摄像头、麦克风和外部应用权限管理
• 密码保存在 macOS 钥匙串
• 登录会话在本机加密保存
• 独立的隐私浏览窗口
• 支持本地 HTML 文件与网页开发检查

Lemon 是一款开源浏览器。你可以查看源码、了解实现方式、审查隐私相关逻辑，也可以参与改进：

GitHub：https://github.com/w3345137/lemon-browser
Gitee：https://gitee.com/binbin3344/lemon-browser

Lemon 不包含广告或分析 SDK，不向开发者上传浏览历史、书签、密码、Cookie 或下载记录。网页内容和网站自身的数据处理规则由相应网站负责。

## App Store 隐私标签建议

选择“不会从此 App 收集数据”。Lemon 的历史、书签、下载记录、密码和会话数据只保存在用户设备或 macOS 钥匙串中，不发送给开发者。用户访问的网站可能独立收集数据，不属于 Lemon 开发者收集。

## 年龄分级建议

如实选择“无限制网页访问”。浏览器可访问开放互联网，预计会得到较高年龄分级；不要为了降低分级而选择“否”。

## 建议截图顺序

1. 浏览器主窗口：仅保留一个公开演示页签，不显示固定标签页、个人书签或历史使用痕迹
2. 多标签页：只使用专门创建的公开演示页签
3. 书签文件夹和书签管理器：只使用演示数据
4. 下载管理器：只使用公开演示文件
5. 网站信息与权限面板
6. 设置中的密码和网站数据管理：不得出现真实账号或网站数据

截图不得包含公司内网、真实账号、个人书签、固定标签页、浏览历史、Cookie、密码或下载记录。使用公开网站和专门准备的演示数据。
